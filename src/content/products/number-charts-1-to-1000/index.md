Ten fill-in number charts that take children from 1 all the way to 1000, one hundred at a time.

Each page is a 10 × 10 chart with the first and last number of every row filled in. Children write the missing numbers, which builds counting, number writing and a feel for place value: the ones change across a row and the tens change down a column.

**How to use:** start with 1 to 100 and move on one page at a time when the child is ready. Pair it with the Montessori hundred board or bead chains: build it, then write it. Great for morning work, math centers, homeschool and early finishers.
